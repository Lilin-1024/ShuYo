# ShuYo App Store Demo Data

此目录包含随 Flutter 应用打包的、已脱敏的离线演示数据。

- `academic/`：课表快照。
- `announcements/`：4 条通知公告及本地详情文本。
- `classroom/`：GA 楼 2026-09-01 快照，仅用于展示空教室界面。
- `course_ratings/`：20 条最新评论及其本地搜索/详情关联数据。
- `forum/`：论坛主题、主题详情、分类、通知、私信及 `admin` 演示资料。

所有写操作均由 demo 数据仓库在本地内存/本地存储中处理，不会上传到服务器。
外部 URL、网络图片、WebView 和真实账户 Cookie 在 demo 状态下均不会使用。

## 当前范围

- 课表、通知公告和论坛（主题、回复、私信、搜索、点赞、收藏、删除）使用本地样本。
- 空教室仅提供 GA 楼 2026-09-01 快照；不扩展其他日期或楼栋数据。
- 课程评价只使用这 20 条已整理的最新评论及其关联结果，不扩展新的样本。
- 设置页的“退出演示”会清除演示标记并回到正常登录流程。

退出演示后，应用重新加载正常仓库和网络设置；正常登录链路与 Demo 数据相互隔离。
